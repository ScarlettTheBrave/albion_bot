# albion_bot

Discord-бот для отслеживания attendency игроков гильдии, на основе парсинга килборда сражений. Собирает статистику сражений, считает посещаемость за заданный промежуток времени и автоматически выдает роль в Discord тем, кто участвовал в файте и зареган в дискорде гильдии.

## Что умеет

Парсит киллборды и сводки сражений из Albion Online.
Ведет учет посещенных боев по каждому игроку за выбранный период.
Связывает игровой ник с профилем пользователя в Discord.
Выдает привязанную роль (по указанному ID роли) всем зарегистрированным игрокам, которые засветились в логах сражения.

## Структура файлов

 `bot.py` - обработка команд Discord, регистрация игроков и логика выдачи ролей.
 `parser.py` - запросы к API киллбордов и разбор участников сражений.
 `db.py` - хранение привязок аккаунтов и истории посещений в SQLite.
 `config.py` - загрузка токена бота и настроек из переменных окружения.

## Установка и запуск

1. Клонируйте репозиторий и создайте виртуальное окружение:
   ```bash
   python -m venv .venv
   .venv\Scripts\activate
   ```


Установите зависимости:

```
pip install discord.py aiohttp python-dotenv
```
Создайте в корне файл .env и укажите токен бота:
Фрагмент кода
```
TOKEN=ваш_токен_discord_бота
Запустите бота:
```

Bash
`python bot.py`
